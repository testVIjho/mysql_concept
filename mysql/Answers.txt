1.What is the difference between include and require in PHP?include and require are both used to load another PHP file into the current script. The difference is that if the file is not found, include gives a warning and the script continues execution. require gives a fatal error and stops the script. So, I use require for important files like database connections and configuration files, and include for optional files. We also have include_once and require_once to prevent loading the same file multiple times2.When do you use `include\_once` and `require\_once`?I use require_once for important files such as configuration files, database connection files, or files containing common functions and classes. If the file is missing, the application should stop.I use include_once for optional files that should be included only once but are not critical for the application to run.3.What is the difference between a Session and a Cookie?"Both Session and Cookie are used to store user-related data, but the main difference is where the data is stored.A Session stores data on the server, and only a session ID is stored in the browser.A Cookie stores data directly in the user's browser.Sessions are more secure because sensitive data remains on the server. Cookies are less secure since users can view or modify them.Sessions usually expire when the browser is closed or after a timeout, while Cookies can have a custom expiration date and persist for days, months, or years."Example Use CasesSession: User login authentication, shopping cart data, user permissions.Cookie: "Remember Me", language preference, theme preference."A Session stores data on the server, while a Cookie stores data in the user's browser.
